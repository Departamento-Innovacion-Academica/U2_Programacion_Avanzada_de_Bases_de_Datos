Ejemplo de particionamiento por rango

RANGE
CREATE TABLE ventas (
id_venta NUMBER,
fecha DATE,
total NUMBER
)
PARTITION BY RANGE (fecha) (
PARTITION ventas_2022 VALUES LESS THAN (TO_DATE('01-01-2023', 'DD-MM-YYYY')),
PARTITION ventas_2023 VALUES LESS THAN (TO_DATE('01-01-2024', 'DD-MM-YYYY')),
PARTITION ventas_2024 VALUES LESS THAN (MAXVALUE)
);
Este ejemplo muestra cómo los registros de la tabla ventas se distribuyen en diferentes particiones según el año de la fecha.
