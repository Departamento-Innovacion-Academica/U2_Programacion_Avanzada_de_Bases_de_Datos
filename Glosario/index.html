Glosario

Cardinalidad

Hace referencia al número estimado de registros que una consulta puede devolver o procesar durante su ejecución. Esta estimación ayuda al sistema gestor de bases de datos a decidir la forma más eficiente de ejecutar una consulta.

Costo de consulta (Query Cost)

Es una estimación que realiza el sistema gestor de bases de datos sobre los recursos que podría consumir una consulta, como tiempo de procesamiento o acceso a disco. Con base en esta estimación, el sistema selecciona la estrategia de ejecución más conveniente.

Estadísticas de la base de datos

Información que el sistema gestor recopila sobre el contenido de las tablas y los índices, como la cantidad de registros o la distribución de los datos. Estas estadísticas son utilizadas por el motor de la base de datos para optimizar la ejecución de consultas.

Hash Join

Técnica utilizada por el sistema gestor de bases de datos para combinar información de dos tablas utilizando una estructura de tipo hash. Este método suele emplearse cuando se manejan grandes volúmenes de datos.

Índice (Index)

Estructura que permite localizar registros dentro de una tabla de manera más rápida. Los índices funcionan de forma similar al índice de un libro, ya que facilitan encontrar información sin necesidad de recorrer toda la tabla.

Index Scan / Index Seek

Formas en que el sistema gestor de bases de datos utiliza un índice para acceder a los datos. En algunos casos el sistema puede localizar directamente los registros necesarios, mientras que en otros recorre una parte del índice para obtenerlos.

Merge Join

Método utilizado para combinar registros de dos tablas que se encuentran ordenadas según las columnas utilizadas en la consulta. Este tipo de unión puede ser eficiente cuando los datos ya están organizados de forma adecuada.

Nested Loop Join

Estrategia de unión en la cual el sistema compara los registros de una tabla con los registros de otra para encontrar coincidencias. Es común cuando una de las tablas contiene pocos registros o cuando existen índices que facilitan la búsqueda.

Optimizador de consultas (Query Optimizer)

Componente del sistema gestor de bases de datos encargado de analizar una consulta y determinar la forma más eficiente de ejecutarla, evaluando diferentes alternativas de acceso a los datos.

Particionamiento (Partitioning)

Técnica que permite dividir una tabla grande en partes más pequeñas llamadas particiones. Esto puede facilitar la administración de grandes volúmenes de información y mejorar el rendimiento de ciertas consultas.

Plan de ejecución (Execution Plan)

Descripción de los pasos que seguirá el sistema gestor de bases de datos para ejecutar una consulta. Este plan muestra cómo se accederá a las tablas, si se utilizarán índices y cómo se combinarán los datos.

Table Scan

Proceso mediante el cual el sistema revisa todos los registros de una tabla para encontrar los datos solicitados en una consulta. Esto suele ocurrir cuando no existen índices adecuados o cuando el sistema considera que es la opción más eficiente.
