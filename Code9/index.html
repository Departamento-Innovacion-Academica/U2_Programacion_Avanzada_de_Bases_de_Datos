Ejemplo de consulta poco eficiente

Ineficiente
SELECT *
FROM empleados
WHERE departamento = 'VENTAS';
Aunque esta consulta es válida, recuperar todas las columnas puede generar un mayor volumen de datos transferidos.

Versión optimizada

Optimizado
SELECT nombre, salario
FROM empleados
WHERE departamento = 'VENTAS';
Al limitar las columnas recuperadas, se reduce la cantidad de datos procesados por el sistema.
